# N2 - Projeto e Arquitetura de Software

Material da atividade N2 desenvolvido a partir do projeto TravelBuddy da disciplina de Programação Web.

## Entregas

- `atividade-n2-travelbuddy.pdf`: documento consolidado para leitura e entrega no Teams.
- `arquitetura-ddd.md`: proposta de arquitetura orientada a domínio, seus contextos e organização de código.
- `mensageria-c4.md`: proposta de comunicação assíncrona, justificativas e fontes Mermaid dos diagramas C4.
- `analise-solid.md`: metodologia reprodutível e seis achados apoiados em trechos do código atual.

O conteúdo arquitetural é uma proposta acadêmica; não modifica o runtime da aplicação. A análise SOLID descreve o código existente na revisão desta atividade.
